模块按「契约 vs 适配器」切分为两层：
- `client.go`、`options.go`、`logger.go` 构成纯 REST 客户端层，暴露 `WorkflowClient`（含 `NewClient`/`Close`/`SubmitWorkflow`/`GetWorkflow` 等）及 `ClientOptions`，依赖仅根 `bconf`、`log`，不感知任何上层 Provider。
- `contract/contract.go` 是契约装配层，提供 `Provider(ctx, *bootstrapv1.Workflow) (any, func(), error)`，将 `bootstrapv1.Workflow.Argo` 字段映射为 `argo.ClientOptions` 并构造客户端，返回 cleanup 闭包；该包单向 import `workflow/argo`，从而让业务方按需引入时依赖图可见。
- 客户端内部通过 `newRequest`/`doRawRequest`/`doRequest` 三层封装统一处理 JSON marshal/unmarshal、Bearer Token、2xx 状态码校验与非空 ctx 超时保护；`go.mod` 使用 replace 指向仓库内 `../../bconf` 与 `../../log`，使本模块作为独立 go module 可被其它 adapter 复用。
