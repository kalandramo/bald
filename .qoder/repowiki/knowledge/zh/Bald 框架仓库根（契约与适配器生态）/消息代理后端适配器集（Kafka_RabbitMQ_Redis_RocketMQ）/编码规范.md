- 每个后端的 contract.Provider 函数签名统一为 `func(ctx context.Context, cfg *bootstrapv1.Broker) (any, func(), error)`，并在文件末尾用 `var _ func(...) = Provider` 做编译期类型守卫。
- Provider 内部先校验配置段是否存在、必填字段是否缺失，再组装 `[]broker.Option`，调用 `NewBroker(opts...).Init().Connect()`，最后返回带 `Disconnect` 的 cleanup 闭包。
- URL 类地址（rabbitmq url、redis address）在进入底层 SDK 前统一做前缀补全与 userinfo/db path 注入，避免裸地址直接传给 SDK。
- 认证相关参数（用户名/密码/密钥）一律作为可选字段处理：为空则跳过，非空才 append 到 options 切片，不改变其他选项的顺序。
