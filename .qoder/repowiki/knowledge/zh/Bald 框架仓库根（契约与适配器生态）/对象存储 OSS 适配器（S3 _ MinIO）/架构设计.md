每个后端（oss/s3、oss/minio）采用「契约 vs 适配器」双层结构：
- `contract/` 子包是契约面，暴露 `Provider(ctx, cfg)` 构造函数以及面向 appkit 的 `AppProvider()`，把既有 Provider 产物以 `appkit.NewKey[*Storage]("storage.s3"|"storage.minio")` 类型化句柄落进引擎资源容器；该层只依赖根模块的 `pkg/appkit`，不被根模块反向 import。
- 包根目录（client.go / config.go / storage.go）是 SDK 适配器面，封装 aws-sdk-go-v2/service/s3 或 minio-go/v7 的具体调用，对外暴露 `*Storage` 或裸 SDK Client。
- 两个后端在 contract 层的结构完全对称：`Segments()` 返回段路径，`Plan()` 声明 `PhaseBootstrap` + `PriorityStorage` + `EffectName: "appkit:storage-clients"`，`Build()` 复用本包的 `Provider` 并返回 `map[string]any{"s3":st}` / `{"minio":st}`。
- 依赖方向单向：adapter → root (`log`)，contract → adapter + root (`pkg/appkit`)，根模块不依赖任何 adapter。
