- 每个适配器根包导出一个扩展了 log.Logger 的本地 Logger 接口，并在其上附加后端特有方法（如 GetProducer、GetHub、Close）。
- 通过 options.go 中的 Option 函数切片 + defaultOptions 初始化模式构造 Logger，由调用方按需 WithXxx 注入配置。
- contract/ 子包统一以 Type 常量 + Provider(ctx, *bootstrapv1.Logger_Backend) 形式暴露，仅做配置段解析与选项拼装，不直接持有任何业务逻辑。
- post 方法内统一先 append(extra, ContextAttrsToArgs(ctx), keyvals...)，再以 i+1<len(all) 步进读取键值对，确保 extra → ctx → 调用参数三者的覆盖顺序一致。
- With 派生实例通过复制 extra 切片并 append 新键值的方式实现不可变上下文累积，同时共享底层 producer/buffer/hub。
- 云端/网络型后端在 post 中同步构建条目后交由 SDK 异步发送，Close 负责等待缓冲刷盘；Enabled 默认返回 true，表示不拦截级别。
