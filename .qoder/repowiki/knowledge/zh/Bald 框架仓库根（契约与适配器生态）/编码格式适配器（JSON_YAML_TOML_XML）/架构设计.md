模块由四个独立 Go module 组成（encoding/json、encoding/yaml、encoding/toml、encoding/xml），每个子目录都是一个独立的 `go.mod`，单向依赖根模块的 `github.com/kalandramo/bald/encoding` 接口包，自身不引入任何其它适配器或业务层。

- 统一契约：每个子包暴露 `Name` 常量与 `New() encoding.Codec` 工厂函数，并通过 `var _ encoding.Codec = codec{}` 做编译期类型断言，确保结构体实现 `Marshal(v any) ([]byte, error)` / `Unmarshal(data []byte, v any) error` / `Name() string` 三个方法。
- 注册模式是显式的：注释明确写清“通过 `encoding.MustRegister(...)` 注册”，编码器在首次被引用时不会自动完成自注册，调用方负责调用 `MustRegister`。
- 底层实现直接委托第三方库：json/xml 走标准库 `encoding/json`、`encoding/xml`；yaml 走 `gopkg.in/yaml.v3`；toml 走 `github.com/BurntSushi/toml`（其中 Marshal 使用 `bytes.Buffer` + `toml.NewEncoder` 以返回字节切片）。
- 每个子包仅含一个 `*.go` 源文件加对应 `_test.go`，无内部子目录，依赖方向严格单向：adapter → encoding 契约。
