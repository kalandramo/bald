- 每个子包暴露 `Name` 字符串常量与 `New() encoding.Codec` 工厂函数，作为该格式的唯一入口。
- 通过 `var _ encoding.Codec = codec{}` 变量声明对 `encoding.Codec` 接口进行编译期校验，确保实现不漂移。
- Marshal/Unmarshal 签名统一为 `(v any) ([]byte, error)` 与 `(data []byte, v any) error`，Name() 直接返回包级 `Name` 常量。
- 编码器结构体为无字段空结构体（`type codec struct{}`），Marshal/Unmarshal 以值接收者实现，避免共享状态。
- 子包注释中显式写出“Registration is explicit: encoding.MustRegister(...)”提示，表明自注册不在导入副作用中完成。
