- 每个 module 将契约装配放在 `contract/` 子包，顶层包不 import `bconf`，以保持 SDK 层零契约依赖。
- `contract.Provider` 统一遵循 `(ctx, *bootstrapv1.Ai) (any, func(), error)` 函数签名，并通过文件末尾的 `var _ func(...) = Provider` 做编译期类型守卫。
- `buildConfig` 采用 fail-fast 校验：`model_type` 仅允许 1(local)/2(cloud)，cloud 型强制要求 `api_key`，local 型强制要求 `host`，错误信息以 `"ai: ..."` 前缀统一格式化。
- 三后端共享同形 YAML 段（`model_type`/`model_name`/`timeout_seconds`/`cloud`/`local`），但各自在本地实现一份独立的 `buildConfig`，不抽取公共映射包。
