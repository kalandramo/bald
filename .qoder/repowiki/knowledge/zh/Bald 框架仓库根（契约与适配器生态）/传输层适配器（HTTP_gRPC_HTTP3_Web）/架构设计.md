本模块由四个独立 Go module 组成，均单向依赖根 `github.com/kalandramo/bald/transport` 契约包：
- `transport/http`（httpserver 包）：封装标准库 `net/http`，根据 `bootstrapv1.Server_Http.Tls` 决定走 `Serve` 或 `ServeTLS`；不注册任何路由，仅提供 `Start/Stop/Endpoint/Options/AttachHandler`。
- `transport/grpc`（grpcserver 包）：封装 `google.golang.org/grpc`，在 `NewGRPCServerWithRegister` 路径中自动注册 gRPC 标准健康服务（`grpc.health.v1`），通过 `HealthServer()` 暴露写入口供装配层同步业务就绪状态；ALPN 强制注入 `h2`。
- `transport/http3`（http3 包）：基于 `quic-go/http3` 自建轻量服务器，内嵌 gorilla/mux 路由器，提供 `Use/Route/Handle*` 等中间件与路由 API，并在无 TLS 配置时生成自签证书以支持测试。
- `transport/web`（web 包）：强绑定 gin，定义泛型 `Handler[T,R]` 与 `Validator[T]`，提供 `HandleJSONRequest/HandleQueryRequest/HandleUriRequest/HandleAllRequest` 四类入口，并通过 `protobind.go` 实现与 grpc-gateway 同源的 proto JSON 语义（`BindProtoRequest` / `WriteProtoResponse`）。

并发模型上，HTTP 与 gRPC 适配器共享同一模式：监听器 `ln` 由 `sync.RWMutex` 保护，`Start` 写入、`Endpoint` 读取、`Stop` 调用优雅关闭；未监听时 `Endpoint` 返回空字符串供 `appkit.waitForEndpoints` 等待。错误语义统一经 `pkg/berrors` 映射为 HTTP 状态码。
