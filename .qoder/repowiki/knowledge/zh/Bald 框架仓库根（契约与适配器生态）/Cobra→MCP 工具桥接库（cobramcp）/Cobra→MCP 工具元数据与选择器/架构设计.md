模块由三个正交文件组成，共同承担 Cobra 到 MCP 的「元数据 → 契约 → 路由」三段：
- `annotations.go`：定义 `AnnotationTitle` / `AnnotationReadOnly` / `AnnotationDestructive` / `AnnotationIdempotent` / `AnnotationOpenWorld` / `AnnotationOutputJSON` 等键，把 `cmd.Annotations` 映射到 `mcp.ToolAnnotation`；其中 `outputJSONHint` 是 cobramcp 自用的私有约定，不进入协议层。
- `schema.go`：声明运行时数据结构 `ToolInput`（含 `CmdPath`、扁平参数 `FlatInput`、`FlagNames`、`ArgNames`）和输出结构 `ToolOutput`，作为 MCP 调用入口与 cobra 执行之间的契约。
- `selector.go`：核心编排层。`Selector` 通过 `CmdSelector`/`FlagSelector` 过滤命令与标志，`buildFlatSchema` 用 `google/jsonschema-go` 生成扁平 JSON Schema（所有 flag 与位置参数都成为顶层 property，禁止额外字段），并把 flag 名集合与位置参数规范存入 `toolMeta` 供执行时拆分输入；`createToolFromCmd` 组装 `mcp.Tool` 名称、描述、RawInputSchema 与注解；`execute` 提供 panic 兜底与可选 `MiddlewareFunc` 钩子。依赖方向单向指向 `internal/bridge/flags` 以复用 flag→schema 转换逻辑。
