- 对 `cmd.Annotations` 中的布尔值一律经 `boolAnnotation` 解析，解析失败仅记录 `baldlog.Warn` 后跳过，不中断注册流程。
- Cobra 命令暴露为 MCP 工具时采用扁平 schema：flag 与位置参数全部提升到顶层 object 属性，并通过 `toolMeta.flagNames`/`argSpecs` 在执行时反向拆分。
- 选择性暴露通过函数式 `CmdSelector`/`FlagSelector` 组合，且基本安全过滤（hidden/deprecated/non-runnable/built-in）始终优先于用户选择器。
- 工具名称由 `toolName` 把 `CommandPath()` 的空格替换为下划线并拼接前缀生成，以避免与命令内部下划线语义冲突。
