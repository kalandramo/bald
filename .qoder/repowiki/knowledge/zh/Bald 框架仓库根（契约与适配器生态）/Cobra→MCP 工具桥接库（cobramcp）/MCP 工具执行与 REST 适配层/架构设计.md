本模块是 cobramcp 包内负责「工具发现 → 执行 → 传输」的叶子层，按职责拆为三个文件：
- `tools.go`：定义 `toolCommandFlags` 并构造 `mcp tools` cobra 子命令，将 `Config.registerTools` 产出的工具清单以缩进 JSON 写入 `mcp-tools.json`。
- `execute.go`：核心执行引擎。启动时解析当前二进制路径（`initExecPath`）；`execute` 通过 `execSubprocess` 重新 fork 自身进程来运行目标 cobra 命令，把 stdout/stderr/退出码封装为 `ToolOutput`；`buildCommandArgs` + `splitFlatInput` + `buildFlagArgs` 把扁平的 `ToolInput` 还原为 cobra/pflag 可理解的参数序列（bool true 省略值、slice 重复 --flag、map 转为 key=value）。
- `restcmd.go`：定义 `restCommandFlags` 并构造 `mcp rest` 子命令，启动 HTTP 服务把每个 cobra 命令映射到 `POST /{toolName}`，请求体为扁平 JSON，响应体含 stdout/stderr/exitCode，并通过 `applyAuthFlags` 注入静态 token 或 RFC 9728 OAuth metadata。
依赖方向单向向外：本模块依赖 `github.com/spf13/cobra`、`github.com/mark3labs/mcp-go/mcp`、`github.com/kalandramo/bald/log`，不反向引用任何适配器或 transport 实现。
