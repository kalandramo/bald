- cobra 子命令通过返回 `*cobra.Command` 的工厂函数（如 `toolCommand`、`restCommand`）装配，并在 `RunE` 中先对 nil config 做防御性初始化再委派给 `Config` 方法。
- 命令行标志统一用带前缀的结构体（`toolCommandFlags`、`restCommandFlags`）承载，并通过 `cmd.Flags().StringVar/IntVar/StringArrayVar` 绑定后在 `RunE` 中使用。
- 日志输出通过 `baldlog.Info/Debug/Error` 在关键路径（收到请求、构建参数、子进程失败）记录结构化字段，而非直接 fmt.Printf。
- 需要可重现的参数序列化时显式排序键集合（如 `buildFlagArgs` 中对 flag 名 `sort.Strings`），以避免 map 迭代顺序不确定性导致日志不可比较。
