模块由三部分组成：
- `server.go` 定义核心类型 `MCPServer` / `MCPOptions` / `Selector`，通过 `cmdFactory func() *cobra.Command` 在每次工具调用时生成独立命令树，从而避免跨并发调用的共享可变状态；协议栈、监听与优雅停机全部委托给 `bald/transport/mcp`（`mcptransport.Server`），本包仅负责「工具从哪来」和 Cobra → MCP Tool 的映射。
- `start.go` 与 `stream.go` 分别实现 `mcp start`（stdio 传输）和 `mcp stream`（SSE HTTP 传输）两个 cobra 子命令，二者都通过 `config.serveStdio` / `config.serveHTTP` 把配置转为 `MCPOptions` 并启动服务。
- 依赖方向单向向外：本包依赖 `github.com/mark3labs/mcp-go/server`、`spf13/cobra` 以及同仓库的 `bald/transport/mcp`；不反向依赖任何适配器或 appkit 装配层，`MCPServer` 满足 `bald transport.Server` 契约以便被上层注入。
- 认证中间件通过 `AuthMiddleware` 函数类型与 `AuthToken` 静态 token 两种方式组合，且 OAuth 资源元数据端点 (`ProtectedResourceMetadataPath`) 始终免认证。
