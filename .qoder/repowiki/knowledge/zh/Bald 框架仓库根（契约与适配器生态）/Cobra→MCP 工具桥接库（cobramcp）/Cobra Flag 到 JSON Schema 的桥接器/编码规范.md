- 对未知或非法输入采用「降级 + 告警」策略：无法解析的类型回退为 string，无法解析的数组元素被跳过并调用 `baldlog.Warn` 记录，而不是返回错误。
- 通过 Cobra `pflag.Flag.Annotations` 键值对注入元信息，如 `cobra.BashCompOneRequiredFlag` 表示必填、自定义 `jsonschema` 键承载内联 JSON Schema。
- 类型分派统一使用基于字符串的 switch 语句，匹配 `flag.Value.Type()` 返回值（如 `intSlice`、`float64Slice`、`stringToString`）来决定 JSON Schema 的 type/items/additionalProperties。
