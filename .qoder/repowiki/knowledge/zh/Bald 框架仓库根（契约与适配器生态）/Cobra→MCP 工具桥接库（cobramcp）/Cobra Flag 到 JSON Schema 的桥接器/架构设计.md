本模块是 cobra_mcp_bridge 适配器内部的一个纯转换层，位于 `cobramcp/internal/bridge/flags`，对外只暴露两个入口：`AddFlagToSchema`（把单个 `pflag.Flag` 注入到 `jsonschema.Schema.Properties`）与包级函数链 `setDefaultFromFlag` → `parseArray` / `parseObject`。
- 依赖方向单向向外：仅依赖 `spf13/pflag`、`spf13/cobra`（读取 `BashCompOneRequiredFlag` 注解标记必填）、`google/jsonschema-go`（产出 Schema），以及根仓库的 `bald/log` 做告警/调试输出；不反向依赖任何上层 cobra 命令定义。
- 类型映射集中在 `flags.go` 的 switch 分支，按 pflag 的 `Value.Type()` 字符串分派为 JSON Schema 的 `boolean`/`integer`/`number`/`string`/`array`/`object`，并对 string-to-int/map 等复合类型附加 `AdditionalProperties`。
- 默认值解析在 `default.go` 中独立实现，支持 pflag 的 `[a,b,c]` 序列表示法与 `key=value` 对象表示法，非法元素以 `baldlog.Warn` 跳过而非报错，保证对第三方 flag 定义的鲁棒性。
- 扩展点通过 Cobra 的 `Annotations` 机制：`cobra.BashCompOneRequiredFlag` 标记必填，自定义 `jsonschema` 注解可让某个 string flag 覆盖整段 schema（JSON 反序列化后替换）。
