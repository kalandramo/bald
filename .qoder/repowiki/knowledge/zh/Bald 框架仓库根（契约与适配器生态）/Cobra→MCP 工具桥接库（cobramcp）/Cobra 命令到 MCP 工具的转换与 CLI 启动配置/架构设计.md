本模块是 cobra-mcp 适配器的入口层，围绕三个职责切分：
- `args.go`：基于 Cobra 的 `cmd.Use` 字符串正则解析 `<name>` / `[name]` / `...` 等位置参数语法，生成 `ArgSpec` 切片；通过 `cmd.Annotations["cobramcp.arg.<index>"]` 注入语义描述，最终产出 MCP Tool 的参数 JSON Schema（依赖 `github.com/google/jsonschema-go`）。
- `config.go`：定义 `Config` 结构体，暴露 `CommandName` / `Selectors` / `DefaultEnv` / `ToolNamePrefix` / `BaseURL` / `AuthMiddleware` / `AuthToken` / `OAuthProtectedResource` / `ServerDescription` 等配置项；提供 `serveStdio`、`serveHTTP` 两个启动器，内部委托 `newTransportServer` 调用 `bald/transport/mcp` 构建底层 Server，并把工具注册结果 (`c.tools`, `c.toolMetas`, `c.toolSelectors`) 注入 transport 层。认证路径由 `publicAuthPaths()` 派生 RFC 9728 的 `.well-known/oauth-protected-resource` 并始终放行。
- `logger.go`：实现 `bald/log.Logger` 接口的 `stderrLogger`，使用标准库 `log/slog` 输出到 `os.Stderr`，避免在 stdio 模式下污染 MCP 协议通道；仅对 CLI 子命令通过 `installStderrLogger` 安装，进程内模型保持静默 nop。

依赖方向单向向外：本模块依赖 `spf13/cobra`、`mark3labs/mcp-go`、`kalandramo/bald/log`、`kalandramo/bald/transport/mcp`，不被这些包反向引用；它是根 module 与适配器之间的薄包装层。
