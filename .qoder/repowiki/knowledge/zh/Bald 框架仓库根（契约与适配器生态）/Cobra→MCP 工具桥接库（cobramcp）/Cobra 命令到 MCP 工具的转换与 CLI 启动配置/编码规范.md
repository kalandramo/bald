- CLI 子命令的位置参数通过 Cobra `cmd.Use` 中的 `<name>` / `[name]` / `...` 语法声明，并由 `parseArgSpecs` 统一解析为 `ArgSpec`，而非使用 Cobra flag 或自定义解析逻辑。
- 位置参数的自然语言描述优先取自 `cmd.Annotations` 中键名为 `AnnotationArgPrefix + <index>` 的条目，否则回退到根据 token 形态合成的默认描述。
- 服务启动器 (`serveStdio` / `serveHTTP`) 统一先 `Start`，再等待 `cmd.Context().Done()` 或传输层 `Done()`，最后用带 `shutdownTimeout` 超时的 context 调用 `Stop` 做优雅停机。
- HTTP 认证通过外层 `AuthMiddleware` 包裹内层 `AuthToken` 静态 Bearer 校验的组合方式装配，且 OAuth 资源元数据发现路径通过 `publicAuthPaths()` 显式放行。
