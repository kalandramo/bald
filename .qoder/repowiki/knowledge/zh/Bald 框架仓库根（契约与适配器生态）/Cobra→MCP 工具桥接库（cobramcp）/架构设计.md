本模块以 cobra 命令树为中心，围绕「注解→Schema→Tool→执行」的单向链路组织子模块：
- `internal/bridge/flags` 把 pflag 定义翻译为 jsonschema-go Schema，被 `tool_metadata` 消费生成 MCP Tool JSON。
- `tool_execution` 在 Cobra 命令上挂载 MCP tools 导出，并通过自进程重入实际运行目标 CLI；`auth_and_rest` 在此基础上提供 Bearer Token 认证中间件和 REST 端点适配层。
- `mcp_server_lifecycle` 负责把整棵命令树注册为 MCP Server，并对外暴露 `mcp start` / `mcp stream` 两个入口，分别走 stdio 与 SSE 传输。
- `cfgmgr_cli` 通过 cursor/vscode 两套 CLI 子命令调用共享的 manager，编辑 MCP 服务器 JSON 配置文件，属于横切运维能力。
- `examples` 作为独立 Go module 演示三种集成形态，反向 require 本库验证契约。
所有子模块统一依赖根仓库的 `bald/log` 与 `bald/transport/mcp`（通过 go.mod replace），并由本模块自身 `github.com/kalandramo/bald/cobramcp` 作为唯一对外包路径。
