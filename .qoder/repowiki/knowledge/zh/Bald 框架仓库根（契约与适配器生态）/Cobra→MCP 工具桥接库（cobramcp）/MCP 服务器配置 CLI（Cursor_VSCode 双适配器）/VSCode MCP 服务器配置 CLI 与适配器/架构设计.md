模块按「CLI 层」与「管理器层」两层划分：
- `cmd/vscode/` 是 Cobra 子命令入口，`root.go` 暴露 `Command(commandName, defaultEnv)` 组装 `enable`、`disable`、`list` 三个子命令；每个子命令通过独立文件 + 闭包 flag struct（如 `enableFlags`）组织参数解析与 `RunE`。
- `manager/vscode/` 是纯业务逻辑层，对外只暴露 `ConfigPath(workspace bool)`、`Server` 结构体及 `Print()`，内部由 `config.go` 读写 JSON、`server.go` 定义 `Server` 模型、`vscode.go` 提供路径抽象，并通过 Go build tag (`vscode_darwin.go`、`vscode_linux.go`、`vscode_windows.go`) 拆分平台默认路径查找实现。
依赖方向单向：CLI → manager/vscode（读取 Server/ConfigPath），同时 CLI 复用上层 `cfgmgr/manager` 提供的 `GetCmdPath`、`DeriveServerName`、`NewVSCodeManager`，不直接操作文件系统。
