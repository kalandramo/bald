模块按「CLI 入口 → 编辑器适配层 → 共享管理器」三层组织：
- cmd/cursor 与 cmd/vscode 各自提供 root、enable、disable、list 四个子命令，仅负责 Cobra 参数解析与调用；
- manager/cursor 与 manager/vscode 是编辑器适配层，把通用的 Server 增删改查操作映射到各自的配置文件路径（.cursor/mcp.json / .vscode/mcp.json）及平台相关行为（darwin/linux/windows 三文件拆分）；
- manager 包本身是纯共享层，集中实现 mcp.json 的加载、保存、备份与 Server 集合的序列化/反序列化，被两个适配器共同依赖。
耦合方向单向：cmd → 对应 adapter → shared manager；两个编辑器之间不互相引用，新增编辑器只需复制 cmd/<editor> 与 manager/<editor> 目录并复用 manager 公共逻辑。
