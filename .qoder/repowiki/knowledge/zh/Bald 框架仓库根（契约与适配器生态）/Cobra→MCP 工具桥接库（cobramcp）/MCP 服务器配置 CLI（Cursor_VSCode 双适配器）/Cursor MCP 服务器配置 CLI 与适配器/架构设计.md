模块按 cobra CLI 层与 cursor 适配器层二分：
- `cmd/cursor/`：cobra 子命令入口，`root.go` 通过 `Command(commandName, defaultEnv)` 组装 enable/disable/list 三个子命令；每个子命令用独立的 struct（如 `enableFlags`）持有 flag，并通过 `manager.GetCmdPath` / `DeriveServerName` 解析当前可执行路径和命令树。
- `manager/cursor/`：cursor 平台适配器，`config.go` 定义 `Config`（`mcpServers` map + inputs）与 `Server` 结构体及其增删查改方法；`cursor.go` 暴露 `ConfigPath(workspace bool)` 统一工作区/用户配置路径选择；`cursor_darwin.go` / `cursor_linux.go` / `cursor_windows.go` 使用 Go build tag 实现各平台的默认路径查找；`server.go` 定义 Server 数据结构与 `Print()` 输出。
依赖方向单向：CLI → manager.cursor，不反向依赖；platform-specific 文件通过文件名后缀在编译期替换，对外只暴露 `ConfigPath` 一个抽象入口。
