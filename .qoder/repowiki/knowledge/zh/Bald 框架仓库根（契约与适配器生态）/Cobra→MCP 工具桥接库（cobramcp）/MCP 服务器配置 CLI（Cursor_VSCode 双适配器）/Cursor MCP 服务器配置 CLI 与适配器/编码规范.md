- Cobra 子命令以独立文件组织（enable.go / disable.go / list.go），由 root.go 中的 `Command` 函数集中装配注册。
- 每个子命令维护一个 `xxxFlags` struct 绑定 flag，并在 `run` 方法中完成业务逻辑，保持 flag 声明与执行分离。
- 平台差异通过 Go build tag 拆分到同名不同后缀的文件（darwin/linux/windows），对外仅暴露统一接口如 `ConfigPath`。
- Server 与 Config 类型均提供 `AddServer` / `HasServer` / `RemoveServer` / `Print` 等对称操作，对外的序列化字段名与 Cursor 官方 schema 保持一致。
