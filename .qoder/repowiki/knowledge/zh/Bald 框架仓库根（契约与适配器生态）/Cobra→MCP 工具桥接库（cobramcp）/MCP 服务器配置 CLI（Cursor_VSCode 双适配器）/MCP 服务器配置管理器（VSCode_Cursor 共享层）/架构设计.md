模块采用「契约 + 适配器」双层结构：
- 契约层 `manager.go` 定义泛型接口 `Config[S server]` 与 `server`，并通过 `Manager[S, C]` 封装 JSON 文件的读取、写入、目录创建及 `.backup.json` 备份；同时暴露 `NewVSCodeManager` / `NewCursorManager` 两个工厂。
- 适配器层 `vscode/` 与 `cursor/` 各自实现该契约：`Config` 对应各自的 JSON 字段名（`servers` vs `mcpServers`），`Server` 表示单个 MCP 服务条目，并提供 `Print()`。
- 平台适配通过 Go build tag 文件（`*_darwin.go` / `*_linux.go` / `*_windows.go`）分离 VSCode 与 Cursor 的配置目录解析逻辑，由 `ConfigPath(workspace)` 统一入口调用。
- 辅助工具 `utils.go` 提供基于 `spf13/cobra` 的命令路径解析与可执行文件名提取，供上层 CLI 使用。
依赖方向单向：`manager` → `vscode`、`manager` → `cursor`；子包之间无相互引用。
