- 每个后端（vscode、cursor）以 `config.go` 实现 `Config` 契约、`server.go` 定义 `Server` 类型并实现 `Print()`，形成一致的契约实现模板。
- 平台差异通过 Go build tag 文件（`_darwin.go` / `_linux.go` / `_windows.go`）拆分，公共 API（如 `ConfigPath`）保持跨平台一致。
- JSON 配置文件写入前先调用 `backupConfig` 生成同名的 `.backup.json` 副本，再原子式覆盖原文件。
- 对缺失的可选字段在 `Print()` 中显式判空后再输出，避免打印零值。
