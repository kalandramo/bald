- HTTP 错误统一通过 `restWriteError` 写入 `Content-Type: application/json` 的 `{error: msg}` 响应，避免分散的手写 error body。
- 认证中间件采用「外层用户中间件包裹内层静态 token 校验」的组合顺序，并在两者均未配置时返回 nil 以禁用认证。
- 需要公开访问的路径（如 OAuth well-known）通过显式的 `publicPaths` / `publicAuthPaths` 白名单跳过认证检查，而非放宽全局规则。
- CLI flag 值合并到 Config 时采用「非零值才覆盖」的策略（`applyAuthFlags`），避免命令行空值意外清空代码中已配置的默认值。
