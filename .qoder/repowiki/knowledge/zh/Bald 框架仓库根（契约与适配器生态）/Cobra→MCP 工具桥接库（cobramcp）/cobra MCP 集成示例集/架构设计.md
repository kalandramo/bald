本模块是纯示例集合，不包含可复用代码，由三个相互独立、各自拥有 `go.mod` 的子 module 组成：
- `positional-args/`：展示 cobra 位置参数的四种声明模式（必填+可选、双必填、可选变参、子命令树），通过 `cobramcp.Command(nil)` 挂载标准 `mcp start/tools/vscode` 子命令树实现 subprocess 模型，并通过 `--in-process` / `serve` 子命令切换为直接调用 `cobramcp.NewMCPServer` 的 in-process 模型。
- `positional-args-mcp-server/`：在 positional-args 基础上进一步封装成独立 MCP Server 二进制，附带 `test-mcp.sh` 端到端测试脚本，验证 stdio 协议下的工具发现与调用。
- `task/`：将 go-task (`taskfile.dev`) 包装为 MCP server，顶层 `main.go` + `mcpserver/main.go` 分离入口与 server 构造，通过 `Taskfile.yml` 驱动本地开发任务，`doc.go` 作为包级文档说明用途。

依赖方向单向指向根仓库的 `github.com/kalandramo/bald/cobramcp`；每个子 module 均配套 `*_test.go`，保持示例即测试的可运行性。
