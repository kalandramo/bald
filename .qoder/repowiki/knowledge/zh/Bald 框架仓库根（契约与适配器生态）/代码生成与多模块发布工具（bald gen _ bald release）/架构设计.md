本模块由两个相互独立的 cobra 子命令包组成，均挂载到根 cmd/bald：

- `internal/codegen`：通过 `app.go` 暴露 `NewCommand`，注册 `gen proto/store/app/domain` 四个叶子。`gen_domain.go` 及其 `gen_domain_*.go` 按 AppSpec.domains 重写域驱动产物；`manifest.go`、`appspec_*.go`、`appspec_build.go`、`appspec_contract.go`、`appspec_validate.go`、`appspec_gen.go`、`appspec_tmpl_*.go` 构成 AppSpec 解析 → 校验 → 构建 → 模板装配的流水线；`gen.go`、`gen_domain_proto.go`、`gen_domain_bind.go`、`gen_domain_cmd.go`、`gen_domain_authz.go` 分别实现不同生成器；模板以 Go 字符串常量内嵌（`protoTmpl`、`entityTmpl` 等），并通过 `text/template` 渲染。
- `internal/release`：通过 `command.go` 暴露 `NewCommand`，注册 `plan/sync/changelog/tag` 四步流水线。`plan.go` 定义 `Plan` 结构体并计算待发布模块，`repo.go` 封装仓库扫描（基于 `scripts/list-modules.sh` 派生清单），`sync.go` 修改 go.mod 内部依赖版本，`changelog.go` 写入 CHANGELOG.md，`tag.go` 调用 git 打标签；`DefaultPlanPath = ".bald/release-plan.json"` 作为本机一次发布的中间产物，不进版本库。

依赖方向：codegen 不依赖 release；release 仅依赖 cobra 与标准库，无外部 SDK。两端均以 `IOStreams` 注入 stdin/stdout/stderr，使测试可注入缓冲而不触碰真实终端。
