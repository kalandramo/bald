- cobra 子命令统一通过 `NewCommand(streams IOStreams)` 工厂函数组装，并在末尾调用 `cmd.SetErr(streams.ErrOut)` 把错误流注入，避免直接绑定 os.Stderr。
- 选项结构体以嵌入 `ioStreams` 或 `IOStreams` 字段的方式复用标准出入流，并在构造函数中通过 `{Field: Default, IOStreams: streams}` 完成初始化。
- 模板以 Go 包级 `var xxxTmpl = ...` 字符串常量声明，并通过 `text/template` 执行渲染，保持模板源与生成逻辑同文件。
- release 子命令遵循 `plan → sync → changelog → tag` 的线性流水线，各命令共享 `loadPlan(path)` 从 `.bald/release-plan.json` 读取计划后再执行业务逻辑。
- 测试通过注入 `IOStreams` 替代真实终端，从而在 CI 中把预期负例错误定向到弃流而不污染日志。
