- 每个 Provider 以 Option func(*config) + defaultConfig() 组合进行函数式构造，并提供 New(opts...) 构造函数。
- 通过 `var _ metrics.Metrics = (*Provider)(nil)` 在文件顶层做编译期契约断言，需要关闭的后端额外断言 `metrics.Closer`。
- 对同一 name 的指标实例进行缓存（map[string]...）并以 sync.Mutex 保护，避免重复创建底层 instrument。
- Counter/Histogram/Gauge 等方法签名统一为 `(ctx context.Context, name string, value float64, labels map[string]string)`，并在方法体内忽略 ctx。
