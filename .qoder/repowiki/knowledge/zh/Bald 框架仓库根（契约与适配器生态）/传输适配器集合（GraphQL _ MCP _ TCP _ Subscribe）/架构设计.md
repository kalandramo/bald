本模块是 wind 框架的「适配器面」，四个子包各自独立 go.mod，单向依赖根模块中的 `transport` 接口与公共库（encoding/metrics/broker），不互相依赖。

- `transport/graphql/`：基于 gqlgen 的 HTTP+GraphQL 服务器，通过 `var _ transport.Server = (*Server)(nil)` 在编译期断言实现 `transport.Server`；内部用 `http.ServeMux` + 中间件链包装，暴露 `KindGraphQL` 常量与 `Middleware` 类型别名以复用 `transport/http` 中间件。
- `transport/mcp/`：基于 mark3labs/mcp-go 的多形态 MCP 服务器（STDIO / SSE / StreamableHTTP / IN_PROCESS），通过 `ServerType` 枚举分发不同启动路径；SSE/HTTP 路径同样实现 `transport.Server`，并支持 RFC 9728 Protected Resource Metadata 端点。
- `transport/tcp/`：纯 TCP socket 服务器，实现 session-based 生命周期、按消息 ID 分发的 handler 注册机制，并通过 `SessionManager` 管理连接池；自带 codec（json 默认）、TLS、OpenTelemetry tracer 与 metrics 集成。
- `transport/subscribe/`：仅暴露 `SubscribeOption` 与 `SubscribeOptionMap`，作为 broker.Subscribe 参数的延迟绑定容器，由上层装配时填充 Handler/Binder。

统一模式：所有可运行 server 都遵循 `NewXxx(opts...) → Start(ctx) → Stop(ctx) → Endpoint()` 的生命周期，并通过 options 函数式构造器注入配置。
