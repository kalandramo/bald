- 每个可运行的 Server 类型通过 `var _ transport.Server = (*Server)(nil)` 在包级变量中做编译期接口实现校验。
- 服务器初始化采用函数式 Option 模式：构造函数接受 `...Option` 并在 init() 中逐一调用以填充字段。
- HTTP 中间件链按注册顺序从后往前包裹（`for i := len(s.middlewares) - 1; i >= 0; i--`），保证先注册的中间件最先执行。
- Endpoint() 返回 URL 前缀统一使用包级常量（如 `KindGraphQL`、`KindTcp`、`KindMCP`）拼接 scheme。
