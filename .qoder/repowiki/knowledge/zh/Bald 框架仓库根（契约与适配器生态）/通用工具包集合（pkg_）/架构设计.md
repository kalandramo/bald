本模块是根 module `github.com/kalandramo/bald` 下的纯工具层，每个子目录即一个独立 Go package，彼此之间耦合极简且方向单向：
- `authz/` 仅暴露 `Authorizer` 接口与 `Func`/`AllowAll`/`DenyAll` 适配器，不 import casbin/RBAC，策略引擎外置为 `bald-authz-casbin`；`reload.go` 提供规则热加载钩子。
- `crudbridge/` 通过 `SimpleViewer` 把 bald 的 string 型身份（`contextx.UserID/TenantID`）映射到 `bald-crud/viewer.Context`，是唯一依赖 `bald-crud` 的入口，强调 System/Platform/Tenant 三视图显式声明的安全纪律。
- `fieldmaskutil/` 基于 `protoreflect` 实现 proto FieldMask 的 Filter/Prune/Overwrite/Validate，并调用 `stringcase.ToSnakeCase` 做路径归一化。
- `metrics/` 定义请求级指标抽象 `Recorder`，默认 noop、真实实现用 otel/metric 按 OTel semconv v1.43.0 发射 HTTP/gRPC 延迟与 `bald_audit_events_total`，与顶层 `metrics/`（传输级手工埋点）职责分离。
- `validation/`、`stringcase/`、`id/`、`contextx/`、`testkit/` 均为无外部依赖的纯函数工具包。
依赖方向：工具包只被 transport / middleware / store 等上层消费，不被根业务逻辑反向依赖；除 `crudbridge` 对 `bald-crud` 和 `fieldmaskutil` 对 `stringcase` 外，包间无相互 import。
