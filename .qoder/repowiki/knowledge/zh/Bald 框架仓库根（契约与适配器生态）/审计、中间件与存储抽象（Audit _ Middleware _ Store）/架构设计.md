本模块由三个相互独立但共享 `pkg/contextx`/`pkg/authn` 等基础包的子包组成：
- `pkg/audit`：纯接口层。`AuditEvent` + `Auditor` 接口是零后端耦合的审计契约；`nopAuditor` 为静默默认值；`compose.go` 通过 `NamedBackend` 声明式组装多个 Auditor，支持构造失败逆序回滚与 cleanup 聚合；`multi.go` 广播式扇出到多个后端。
- `pkg/middleware`：按传输分目录（`gin/`、`grpc/`），每个目录都包含同构能力的中间件/拦截器（authn/authz/audit/cors/logging/ratelimit/recovery/requestid/observability/secure），并通过 `shared/` 复用跨传输逻辑；`tracing.go` 在根目录暴露 OpenTelemetry 追踪桥接。所有中间件对业务非阻塞，错误仅记日志或返回标准错误码。
- `pkg/store`：DAL 契约层。`Queryable[T]` + `DBProvider[T]` + 泛型 `Store[T]` 门面，核心不依赖任何具体引擎；租户隔离、平台级豁免、数据范围（DataScope）通过 `scope.go` 的全局注册表注入到 `Where` 条件中；`inmemory/` 是唯一内置实现，专供 e2e 与测试零外部依赖使用。
依赖方向单向：middleware 依赖 audit 与 store 契约，store 依赖 authn/contextx，三者均不反向依赖 gin/grpc 实现。
