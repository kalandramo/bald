- 每个 bconfig 后端子包统一拆分为 `config.go`（实现 Reader/Watcher）、`options.go`（Option 构造）、可选 `watcher.go`（推送式 WatchValue）与同名 `_test.go`。
- 配置加载采用「低优先级→高优先级」的 deepMerge 树（remote → file → env → flag），每次合并产出全新 map，保证 Store 已发布的旧快照不被原地修改。
- 对 repeated 字段的覆盖语义为「整体替换而非追加」：在 UnmarshalMap 中通过 clearPresentLists 清理默认列表，避免 proto.Merge 的 append 行为污染默认值。
- 契约校验与装配解耦：`bconf.Validate` 只检查取值合法性（端口、必填段、枚举值域），是否缺少后端 Provider 留给上层 L3 覆盖检查在启动期报错。
- WatchValue 优先于 Watcher：`FallbackReader` 只聚合实现 `ValueWatcher` 的子源，纯信号型后端需在 provider 内部 Load 回读后再以 ValueWatcher 形式暴露，避免组合层静默丢弃监听能力。
