- 每个 Server 在文件顶部用 `var _ transport.Server = (*Server)(nil)` 编译期断言接口实现，并以 `KindXxx` 常量暴露传输类型标识。
- Server 构造函数采用选项模式 `NewServer(opts ...Option)`，所有可选参数以闭包函数形式注入，未设置项保持零值语义。
- 生命周期通过 `Start(ctx)` 阻塞等待 ctx 取消、`Stop(ctx)` 带超时优雅关停实现，内部使用 `atomic.Bool` 控制 started/stopping 状态及 `stopDone chan struct{}` 供并发调用方等待。
- `*/contract/provider.go` 中的 `AppProvider()` 固定返回 `appkit.Provider`，通过 `Segments() []string{"server.<kind>"}` 与 `Plan(..., PhaseServe)` 声明段驱动装配行为，Build 中把既有工厂产物包装为 `transport.Server`。
- 错误处理优先记录结构化日志而非 panic，并通过可选 Option 覆盖默认行为（如 asynq 的 `WithErrorHandler`、cron 的 `WithLogger`）。
