模块按「契约面 vs 适配器面」切分：每个子目录（asynq、cron、gateway）都自带独立的 go.mod 作为独立 Go module；其中 `*/contract` 子包仅面向 appkit 段驱动装配，导出 `AppProvider()` 把 `server.asynq` / `server.cron` 等配置段映射为 `transport.Server` 并声明 `Segments()` 路径与 `PhaseServe`，而具体 Server 实现留在父包，避免根模块反向依赖适配器的循环。

- `transport/asynq`：封装 hibiken/asynq 的 Server/Client/Scheduler/Inspector，统一 Start/Stop 生命周期，支持 Redis 单节点/集群/sentinel，通过 `KindAsynq` 常量标识类型，默认 ErrorHandler 将 `ErrHandlerNotFound` 提升为可观测日志。
- `transport/cron`：封装 robfig/cron/v3，支持秒级表达式与描述符，构造期一次性构建 scheduler 避免 Recover 链丢失，优雅停机窗口默认 10s 与 appkit stopTimeout 对齐。
- `transport/gateway`：复用 `transport/http.HTTPServer` 承载 mux，延迟到 Start 时建立 gRPC 后端连接；后端地址支持直连或 `discovery:///<服务名>`，通过 `registry.Discovery` 解析端点，TLS 由 `bconf/tlsconf` 派生。

依赖方向单向指向根模块：适配器 require `transport`、`encoding`、`registry`、`bconf/gen/go/bootstrap/v1`、`pkg/appkit`，但根模块不 require 任何适配器。
