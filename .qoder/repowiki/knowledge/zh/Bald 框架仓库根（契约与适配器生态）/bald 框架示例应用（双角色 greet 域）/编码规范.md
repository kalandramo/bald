- 所有由 AppSpec 生成的文件头带 `// Code generated by "bald gen app --spec". DO NOT EDIT.`，用户自定义扩展放在同包 `custom.go` 中以避开重生成。
- 每个业务域在自身包中暴露一个 `appkit.Domain` 变量（如 `greetv1.Domain`），通过 Declare/ApplyNode/Reconcile/Services/RouteTable 五元组完成自装配。
- 可变行为通过 AppSpec `variants` 与对应 `register_*.go` 钩子切换（如 `grpcgw`、`nacos`），变体条件名即 Go build tag。
- E2E 测试集中在 `internal/bootstrap/*_e2e_test.go`，使用同一份 bootstrap 选项驱动真实服务进程，确保测试与生产装配同源。
