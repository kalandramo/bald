- 每个适配器的 contract 包提供 `Provider(ctx, cfg) (any, func(), error)` 工厂，返回 cleanup 供 appkit 停机 Effect 回放，并附带接口守卫 `var _ Cache = (*Impl)(nil)`。
- 选项通过闭包式 Option 函数注入（如 `local.WithSize`、`redis.WithKeyPrefix`、`loadable.WithTTL`），在构造时依次 apply。
- config 解析与校验拆成纯函数（如 `buildOptions`、`validate`），便于单元测试且不与 I/O 耦合。
- contract 包单独隔离，使底层 adapter 保持零 bconf 依赖，只有 contract 层 import bootstrap v1 配置类型。
