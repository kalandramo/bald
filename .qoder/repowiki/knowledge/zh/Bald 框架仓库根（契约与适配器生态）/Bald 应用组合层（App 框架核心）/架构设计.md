模块是 bald 根 module 的组合层（App 层），对外暴露 `App`、`Serve/MustServe` 单一入口以及一组可组合的原语（Effect、Component、Provides/Requires、Mount、Reconcile、OnKeyChange）。内部按职责分层：
- 装配入口：`serve.go` 完成 `--config` 解析 → 契约两遍预装载（文件/远程层 → 解析 `app.name` 派生命名空间 → 挂 env 层重合并）→ 约定装配（`bootstrap.go`）→ `Run`；`plan*.go` 复用同一编译路径输出文本或 JSON 计划。
- 段驱动 Provider 引擎：`provider.go` 定义 `Provider` 接口（`Plan` + `Build` v2 分离），`bootstrap.go` 实现 assemble 循环（声明收集、节点归一、Kahn 拓扑排序、阶段 B/迟后阶段构建、teardownOrder 停机序）。
- 运行时编排：`appkit.go` 中的 `App` 结构体以 errgroup 并发启停、优雅停机（`stopTimeout` 派生各阶段预算）、崩溃级联停止、防重入（`ErrAlreadyRunning`）。
- 扩展原语：`effect.go`（全局注册表逆操作账本）、`capability.go`（Provides/Requires 依赖校验）、`component.go`（Start/Dispose 有状态实例）、`mount.go`（运行期 Mount/Dismount）、`reconcile.go`（diff-apply 期望态协调）、`keywatch.go`（细粒度配置变更订阅）、`domain.go` + `segment_biz.go`（业务段路由与 Reconcile）。
- 子包：`pkg/appkit/mech` 提供可插拔机制注册表（`registry.go`/`mech.go`），`pkg/appkit/appcli` 封装 CLI 启动壳，`pkg/appkit/std` 内置标准后端（HTTP/gRPC/logger 等）作为默认 Provider。
依赖方向单向指向 `bootstrap/config`、`transport`、`registry`、`audit` 等根 module 包，不反向依赖适配器。
