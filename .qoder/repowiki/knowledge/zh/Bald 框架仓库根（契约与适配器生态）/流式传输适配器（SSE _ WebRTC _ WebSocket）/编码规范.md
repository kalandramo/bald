- Server 构造统一采用 `NewServer(addr string, opts ...Option)` + 函数式 Option 模式（如 `WithPath`、`WithTLSConfig`、`WithPayloadType`），默认值在构造函数内初始化后再逐项覆盖。
- 所有 Server 实现 `transport.Server` 接口并在包级用 `var _ transport.Server = (*Server)(nil)` 进行编译期守卫。
- HTTP 中间件以 `Middleware = func(http.Handler) http.Handler` 别名暴露，使 `transport/http/middleware` 下的中间件可直接复用。
- 消息路由通过 `RegisterMessageHandler(messageType, handler, binder)` 按 `NetMessageType` 注册，webrtc 与 websocket 共享同一份 `NetMessageHandlerMap`/`NetMessageHandler` 模型。
- 连接与会话由独立的 `SessionManager` 管理，Server 自身作为 `Observer` 通过 `RegisterObserver(srv)` 接入，在 connect/disconnect 时触发回调。
- payload 编解码走 `encoding.Codec` 抽象，未显式设置时兜底使用 `encoding.GetCodec("json")`，保持二进制与文本两种 `PayloadType` 的一致性。
