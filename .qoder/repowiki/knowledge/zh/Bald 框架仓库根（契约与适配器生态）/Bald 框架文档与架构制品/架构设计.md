文档按读者角色分层组织：
- `docs/architecture/`：面向仓库维护者的架构制品，以 `bald-c4.dsl`（C4 Structurizr DSL）与 `flows.dot`、`module-deps.dot`（Graphviz DOT）为可渲染文本源，经 `tools/check_cites.py`、`tools/check_dot.py` 与 `tools/dsl-validate/Validate.java`（依赖 structurnizr-dsl 6.2.4）进行引用回读、DOT 语法自检和 DSL 解析校验，输出快照存于 `render/`；`README.md` 记录生成命令、环境（graphviz 16.1.0 / Temurin JDK 21 / Maven 3.9.16）与已知未覆盖范围。
- `docs/devel/zh-CN/`：面向开发者的设计文档，每个子系统一个 Markdown（如 Bootstrap、CRUD、传输层、注册中心、熔断等），并有一份 `框架契约总览.md` 汇总所有公开 API 与模块依赖层级（berrors/bconf/log/bconfig → transport → bootstrap → 主模块）。
- `docs/guide/zh-CN/`：面向使用者的指南，覆盖 quickstart、各能力接入（健康检查、指标、授权、日志、MCP 桥接等）。
三者之间不互相 import，仅通过交叉链接关联；源码行号引用是约束性锚点，由 `check_cites.py` 强制验证。
