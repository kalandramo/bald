| 重试 `retry` | 同上，内层 | `login.retry` | `auth.go:252-270`（`queryWithRetry`） |

**分层语义**（外层熔断、内层重试）：
```
Allow ──► [retry: 瞬时故障重试 N 次] ──► MarkSuccess/MarkFailure
```
retry 处理**偶发抖动**，熔断处理**持续故障**（重试仍失败 → 计入失败 → Open 后快速失败，不再让每个请求付出 N 次重试代价）。

**接线位置**：`bald-admin/backend/cmd/go-bald-admin/main.go:344-358`（三处 `SetLogin*`），构造函数 `buildLoginLimiter`/`buildLoginBreaker`/`buildLoginRetrier` 在 `main.go:545/573/606`。

**配置模板**：`bald-admin/backend/configs/go-bald-admin.yaml.example`，三段均为**可选**（缺省即禁用态，不阻断登录）。

## 坑

每条一句话说清后果。

1. **bald 的两条装配路径不可混用**：`FromBootstrap` 用 `With*` 前缀（`BootstrapOption`），`appkit.New` 无前缀（`Option`）——混用会编译失败或静默不生效。
2. **`store.ErrNotFound` 绝不能计入熔断失败、也不能重试**——否则攻击者用几个不存在的用户名就能熔断整个登录（本会话已用 25 次 NotFound 验证熔断器仍 Closed）。
3. **不能用 `circuitbreaker.CircuitBreaker.Execute`**——它对 fn 的任何 error 一律 `MarkFailure`（`hystrix.go:228-231`），会把 NotFound 误计为失败；必须手动 `Allow`/`MarkSuccess`/`MarkFailure` 配对。
4. **`ratelimit.Limiter` 契约：`ok=false` 时伴随 `ErrLimited`**——它是「超限」的正常信号，不是故障。首版把它当故障走 fail-open，导致限流**从未生效**（本会话踩过）。
5. **`grep` 输出被 `storm-collapsed` 折叠时不得下负向结论**——本会话多次遇到输出折叠，必须 `read_file` 读 raw 文件交叉验证（有损观测纪律）。
6. **不要用裸 `git commit` / `git add -A`**——多会话共享工作区，会卷入其他会话的文件（`.TODO` 就是其他会话的）。
7. **不要改全局 `go env` 的 GOPROXY**——本地无外网，用命令级 `GOPROXY=https://goproxy.cn,direct` 即可；改全局会影响其他会话。
8. **`bald-admin` 禁止 `replace` 指向本地 bald**——违反「零 replace」约束，go.mod 顶部注释载明。
9. **`hash_edit` 的锚点是一次性坐标**——本会话因锚点过期插错了行（配置模板内容跑到第 7 行）；改多处时从文件末尾往前改，或改用 `edit_file`（唯一字符串更可靠）。
10. **计划文档的行号锚点会漂移**——计划 L214-L216 描述的场景（JWT 验签重试 / 审计落库熔断）已被本会话推翻，动手前先读本节「当前卡点」的排除清单。
11. **`time.Now().UnixNano()` 不能作唯一键**——Windows 时钟分辨率约 0.5–1ms（实测连续两次调用 99999/100000 同值），连续调用必撞键；macOS 粒度更细会掩盖。用 `uuid`（`file.go:104` 模式）。**同类隐患扫描**：`grep -rn "UnixNano()" internal/` 找所有唯一键生成点。
12. **测试不能用 `broker.Connect()` 判 Redis 可达性**——D13.2 假成功会让 Skip 判据失效；用独立 `Ping`（见 `t_w2_6_broker_e2e_test.go` 的 `requireRedis`）。
13. **etcd/registry 测试必须前置 TCP 可达性探测**——`registry/etcd` 的 contract.Provider 惰性构造不报错，不可达时 `Register()` 会挂起数分钟（Windows 实测触发 go test 10 分钟超时）。见 `t_w4_4_registry_e2e_test.go` 的 `requireEtcdReachable`。
14. **本设备 `deliver_task` 不可用**（工作区根非 git repo）——用限定 pathspec 的 `git add <文件>` + `git commit`，**禁止 `-A`/`-a`**（会卷入其他会话文件）。
