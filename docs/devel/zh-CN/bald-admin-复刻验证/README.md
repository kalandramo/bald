## 给 bald 维护者的两个建议（源自本次验证）

1. **统一「契约段 ↔ provider 注册」的完整性检查**：目前契约声明了某后端
   （如 `audit.backends: store`）但未注册 provider 时，行为从「静默失效」
   （D2/D5）到「启动崩溃」（D14）不等——建议启动期统一 fail-fast 并给出可操作指引。
2. **错误信息质量对齐**：同为「配置缺失」，`etcd.New()` 报
   `etcd: endpoints is required`（好），而 `broker.Connect()` 对不可达 Redis
   返回 nil 假成功（D13.2，差）。建议统一为「可操作」风格。
