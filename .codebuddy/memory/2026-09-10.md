- **云端验证全通**（用户改密后）：REST 登录 → SDK Publish/GetConfig/ListenConfig 三通道 → 服务启动 0 错误 → 运行中向 dataId 发布 v3，秒级触发 `config changed` 热更新日志（nacos 推送 → Store remerge → appkit hotReload 契约重装载）。
- **新坑**：① 云端 nacos（Nacos 3.x）config 通道强制鉴权，错误凭据报 `user not found!`（登录路径 `/nacos/v1/auth/users/login`）；② REST 单条 GET 报 "config data not exist" 是**假阴性**（search=accurate 列表 API 可见、SDK GetConfig 正常），观测别被误导；③ nacos-sdk-go v2 `ListenConfig` 只返回 error 单值（OnChange 回调式，不返回 channel）。
